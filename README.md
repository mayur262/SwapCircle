# SwapCircle
 
## 🎯 Description 
SwapCircle is a community-driven app to swap, rent, donate, and recycle items. It streamlines item discovery, simple checkout flows, and pickup verification using photo proof.
 
## ✨ Features 
- Browse item listings with photos, descriptions, and location
- Checkout flows for Rent (dates + escrow), Donate (borrow for free with dates), Recycle (buy now), and Swap
- Pickup photo verification and in-app messaging with owners
 
## 🛠 Technologies Used 
- Expo (React Native) + React Navigation
- Supabase (database and auth)
- React Native Maps / web map previews
 
## 🚀 How to Run 
1. Clone this repository 
2. Navigate to the project folder: `cd SwapCircle` 
3. Install dependencies: `npm install` 
4. Run the project (web): `npm run web` 
5. Access at: `http://localhost:8081/`
